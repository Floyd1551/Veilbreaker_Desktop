# Veilbreaker Desktop 0.43.0rc1

This preview packages the manual survey-placement and searchable Tools phases.

## Included

- One offline search across existing RF calculators, the subnet inspector and field references.
- RF, Cellular, Wi-Fi, Networking, Fiber & Power and References filters.
- Responsive, keyboard-accessible tool cards that open the established calculator and reference hosts.
- Operator geographic placement and independent multi-floor plan placement for survey scans.
- Floor-plan scale calibration, unplaced-measurement count, spatial edit history and portable survey export assets.

## Evidence boundaries

Manual positions remain operator annotations and never become captured GPS evidence. Calculator results remain calculated estimates and are not silently promoted to measured evidence. Heat-map interpolation, metric-colored survey points, tool presets and cross-feature attachments remain future phases.

## Package scope

This is an unsigned Windows x64 preview. Offline CONUS map, terrain and tower data packs remain separate downloads and are not embedded in the installer. Physical hardware qualification is unchanged from prior releases.
