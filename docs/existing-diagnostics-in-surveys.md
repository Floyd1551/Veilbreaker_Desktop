# Add saved diagnostics to a survey

From Run History, select a diagnostic, choose **Add to survey**, and select an
open survey. Veilbreaker opens the destination survey after adding the test.

From an open survey, choose **Add existing diagnostics**. Search by run, date,
site, scenario or note; check one or more tests and choose **Add selected diagnostics**.
Selections persist across search results and pages. Already included tests are disabled.

Surveys retain their 20-test limit. Reopen completed surveys before adding tests.
Original measurements, site, scenario and evidence remain unchanged; saved results
are included in survey comparisons and report exports without running collection again.
Linked diagnostics remain in Run History even if the destination survey is removed
with its owned tests. Tests from different sites can be deliberately grouped;
check their displayed site and scenario before adding them.
